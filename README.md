# Prayer's Computer 💻

**Prayer's Computer** is an interactive desktop-style application created in JavaFX. The project tells a story through different apps, posts, videos, and hidden information found on Prayer's computer.

The user can explore the computer by opening different applications and interacting with content on the desktop. As more parts of the computer are explored, the user learns more about Prayer, the other characters, and the events happening in the story.

## Features

* Interactive computer desktop
* Clickable applications and icons
* Blog and social media-style posts
* News articles
* Videos
* Background music and sound effects
* Hidden clues and passwords
* Story progression based on what the user explores
* Custom graphics and UI inspired by a dark gothic 2000s tumblr aesthetic

## Story

Prayer's Computer is part of an interactive story involving characters such as **Prayer, Thomas, CyberWoman, and CyberMan**.

The computer contains pieces of information that help reveal the story. Instead of simply reading the story from beginning to end, the player discovers it by exploring files, posts, videos, and other parts of the computer.

The project explores topics surrounding the internet, online communities, artificial intelligence, gender, misinformation, and online safety.

## Technologies Used

* Java
* JavaFX
* IntelliJ IDEA
* Images, audio, and video assets

## How to Run

1. Clone or download the project.
2. Open the project in IntelliJ IDEA.
3. Make sure Java and JavaFX are configured.
4. Run the main JavaFX application.
5. Explore Prayer's computer by clicking the different icons and applications.

## Purpose

The purpose of this project is to combine programming and storytelling to create an interactive experience. The user discovers the narrative by exploring the computer instead of being shown all of the information at once.
